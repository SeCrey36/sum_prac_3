# DocSec — Сервис аудита документов на наличие персональных данных по 152-ФЗ

Клиент-серверное веб-приложение для автоматизированного анализа документов форматов **PDF** и **DOCX** (до 20 МБ) на наличие персональных данных, классификации уровня риска, генерации официальных PDF-протоколов проверки и безопасного уничтожения исходных файлов через 1 час.

Учебный проект производственной практики (СФУ, ИКИТ, кафедра «Программная инженерия»).


## Почему Django (не FastAPI)

1. **OWASP Top 10:** Встроенная защита от CSRF, SQL-инъекций, XSS и безопасные заголовки из коробки, не требующие сборки из разрозненных сторонних пакетов.
2. **Изоляция пользователей (Django Auth + SimpleJWT):** Ролевая модель доступа и надёжное разделение журналов аудита.
3. **Django Admin**
4. **Транзакционность ORM:** Целостность данных при фиксации результатов сложного аудита документов.

## Быстрый запуск
#### Backend (Django)
```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```
Сервер доступен по: `http://127.0.0.1:8000/`

*Примечание:* дефолтно в `.env` включён режим `CELERY_TASK_ALWAYS_EAGER=True`, фоновые задачи выполняются синхронно без обязательного запуска Redis.
С настоящим брокером Celery + Redis:
```bash
brew services start redis
celery -A core worker -l info
```
